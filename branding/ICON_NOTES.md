# Launcher icon — Concept 2

Selected art: Red Dirt Code sunset, curly braces, recipe book, chef's hat,
Oklahoma identity, vegetables and utensils. Keep this concept for My Cookbook.

Android 8+ reads the `mipmap-anydpi-v26` adaptive XML icon layers.
Earlier/legacy launchers use size-specific `mipmap-*/ic_launcher.webp` and
`ic_launcher_round.webp`. The adaptive foreground is visually inset so masks
are less likely to clip the book lettering.

The source of this artwork is `branding/cookbook-icon-concept-2.webp`, a
512-pixel optimized rendering of the approved Concept 2 image. An original
full-resolution copy is retained in the Cookbook Project Library.

Release: 0.2.4-alpha (versionCode 204); app ID unchanged.
Manual visual inspection of the installed Android app is not yet complete.
